# 四种地图瓦片

参考图中的低细节海岛地图，提供 4 个 32×32 px 瓦片：深蓝水面、黄沙、草地、竖向海岸（水在左、草在右，中间有沙）。图集为 128×32 px，4 列×1 行，无边距、无间距、不透明。

在 Godot 4.7 中打开 `res://assets/tile_map/noise_map_four/terrain_noise_map_demo.tscn` 可查看示例。自己的 `TileMapLayer` 可直接引用 `terrain_noise_map.tres`，图集坐标见 `atlas_layout.json`。示例使用最近邻过滤。

这 4 块用于手动绘制。海岸块只有竖向一款，不能自动连接任意形状的岛屿；未设置碰撞和导航。已检查 PNG 尺寸、切片和同类瓦片边缘；当前环境未找到 Godot 可执行文件，导入及运行画面尚未验证。
